# 4. Composite action with hash-locked dependencies

## Status
Accepted (2026-11-19)

## Context
A JavaScript or Docker action would need a build step or a registry. The code is Python, and users
should be able to audit what runs.

## Decision
`action.yml` is a composite action: it sets up Python 3.12, installs from `requirements.lock`
(`pip install --require-hashes --no-deps`, generated by `just lock`), and runs from a neutral
directory with `PYTHONSAFEPATH`. Every third-party action is pinned to a full commit SHA, user
inputs reach scripts only through `env:`, and `zizmor` reports nothing above style hints.

## Consequences
Installs are reproducible and tamper-evident; a dependency bump is a deliberate `just lock`
(Dependabot proposes it, with a 7-day cooldown). The lock file is generated with Python 3.12, the
version the action runs. The SBOM is derived from the same file.
